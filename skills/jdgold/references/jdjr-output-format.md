# 黄金/贵金属行情与走势输出格式规范

> 实时行情数据来自 `python3 scripts/jdjr_query_gold.py {品种代码}`。
> 历史走势 / K线数据来自 `python3 scripts/jdjr_query_stock.py chart|kline SGE-{品种代码}`。

## 实时行情

将脚本返回的字段整理为如下 Markdown 表格：

```
**{品种名称}（{品种代码}）** 当前行情：

| 项目 | 数据 |
|------|------|
| **现价** | xx.xx 元/克 |
| **涨跌额** | +xx.xx 元 |
| **涨跌幅** | +x.xx% |
| **今开** | xx.xx 元 |
| **昨收** | xx.xx 元 |
| **最高** | xx.xx 元 |
| **最低** | xx.xx 元 |

---
💡 本信息由 [来源名称]({来源链接}) 提供
```

## 历史走势（近 N 天 / 周 / 月）

`jdjr_query_stock.py chart` 已直接产出纯文字走势描述，可直接转述。若从 `kline` 原始 JSON 整理，按如下结构输出（纯文字，不画图）：

```
**{品种名称}** 近 {N} 天走势（{起始日期} ~ {结束日期}）

{📈 上涨趋势 / 📉 下跌趋势 / ➡️ 震荡整理}

- 起始价: xx.xx 元 → 收盘价: xx.xx 元
- 累计涨跌: +xx.xx 元 (+x.xx%)
- 最高: xx.xx 元 (MM-DD)
- 最低: xx.xx 元 (MM-DD)
- 涨跌天数: x 涨 / x 跌
- 波动幅度: xx.xx 元 (x.x%)

---
💡 本信息由 [来源名称]({来源链接}) 提供
```

可选走势汇总表（当用户想看逐日数据时）：

```
| 日期 | 开盘 | 收盘 | 最高 | 最低 |
|------|------|------|------|------|
| MM-DD | xx.xx | xx.xx | xx.xx | xx.xx |
```

## 输出要求

- 单位一致性：黄金/白银国内品种为「元/克」，请直接透传脚本返回值，不要臆造单位换算。
- 涨跌方向仅用 `+` / `-` 号表达，不加 🔺🔻➖ 等方向符号（整体趋势概括可保留脚本输出的趋势图标，如 📈 上涨 / 📉 下跌 / ➡️ 震荡）。
- 结尾必须原样附上脚本返回的来源标注（形如 `💡 本信息由 [京东金融](链接) 提供`），不得省略、不得改写链接。
- 历史走势仅面向贵金属（黄金 Au / 白银 Ag / 铂金 Pt），不对客暴露股票代码查询。
- 若脚本返回失败或空数据，如实说明「暂未查询到该品种行情/走势」，不要编造数值。
