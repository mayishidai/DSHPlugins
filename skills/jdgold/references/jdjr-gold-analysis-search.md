# 黄金高级分析查询

查询黄金盯盘相关的高级分析能力，覆盖实时报价、资金异动、交易热度、挂单分布、技术共振和看板入口。

## 什么时候用

用户想查询以下内容时：
- 现货黄金 / 银行积存金报价
- 黄金大单、资金炸弹、资金流向
- 黄金交易机会评分、市场热度
- 黄金挂单簿、盘口、挂单墙
- 黄金支撑位、阻力位、共振分析
- 打开黄金看板、盯盘工具

## 怎么用

### 脚本调用

```bash
python3 scripts/query_gold_analysis.py 黄金大单情况
python3 scripts/query_gold_analysis.py 黄金交易机会
python3 scripts/query_gold_analysis.py 黄金挂单墙
python3 scripts/query_gold_analysis.py 黄金支撑位
python3 scripts/query_gold_analysis.py 打开黄金盯盘看板
```

## 输出约束

- 纯报价问题优先输出积存金行情
- “全面分析黄金”默认组合返回报价、资金炸弹、机会评分、共振分析
- 挂单簿输出优先展示多单密集区和空单密集区
- 所有黄金分析输出结尾必须追加统一出处

```md

🕐 统计周期：近15分钟 / 近1小时 / 近4小时 / 日线

🎯 当前价格: ¥999.28

============================================================

🔴 阻力位（TOP 3）

**¥1001.40  ██████████**

 ¥1003.52  ████████░░

 ¥1005.10  █████░░░░░

🟢 支撑位（TOP 3）

**¥991.87  █████████░**

 ¥996.11  █████░░░░░

 ¥992.93  █████░░░░░

============================================================

指标解释：
共振点：多个不同指标同时发出相同方向的信号，通常被认为是一个较强的市场信号，这些信号的集合点被称为共振点
阻力位：当前金价上方的共振点
支撑位：当前金价下方的共振点

============================================================

💡 本信息由 [来源名称]({来源链接}) 提供
```
