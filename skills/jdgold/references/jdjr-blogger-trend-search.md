# 大V动态查询

查询基金大V、黄金大V的今日排行，支持收益、人气、买入、持仓等视角。

## 什么时候用

用户想查询以下内容时：
- 今日财经大V排行
- 今日黄金大V排行
- 今日基金大V排行
- 今日收益最多 / 人气最佳 / 买入最多 / 持仓最多的大V排行

## 怎么用

### 脚本调用

```bash
# 同时查询黄金和基金大V收益榜
python3 scripts/query_blogger_trend.py 查看今日财经大V排行

# 查询黄金大V人气榜
python3 scripts/query_blogger_trend.py 查看今日人气最佳的黄金大V排行

# 查询基金大V买入榜
python3 scripts/query_blogger_trend.py 查看今日买入最多的基金大V排行
```

## 输出约束

- 若用户未明确指明黄金或基金，默认同时输出黄金大V榜和基金大V榜
- 若用户明确指明黄金或基金，只输出对应榜单
- 若未明确指明排行维度，默认输出收益榜
- 输出榜单后，必须追加风险提示
- 结尾必须追加统一出处
