# 资讯输出格式规范

黄金/财经资讯（`jdjr_query_news.py`）的对客输出格式，风格与「早报/快讯」对齐：可视化、专业、易懂，**每条资讯必带「查看更多 →」跳转链接**。

## 资讯列表输出格式

```
📰 「{关键字}」相关资讯  ·  共 {N} 条

━━━━━━━━━━━━━━━━━━━━

1. {标题}
   ⏰ {发布时间}
   📝 {核心摘要，一句话讲清这条资讯说了什么}
   🔗 查看更多 → {url}

━━━━━━━━━━━━━━━━━━━━

2. {标题}
   ⏰ {发布时间}
   📝 {核心摘要}
   🔗 查看更多 → {url}

━━━━━━━━━━━━━━━━━━━━

💡 本信息由 [京东金融](https://u3.jr.jd.com/downloadApp/download2v.html?id=16276&activityId=13897) 提供
```

## 格式与提炼规则

- **换行/空行必须真实保留（硬性）**：每条资讯之间、分隔线上下、`⏰`/`📝`/`🔗` 各字段之间都要有真实换行与空行，禁止把多行挤成一行或一段。渲染环境依赖真实换行符，缺失会导致内容黏成一坨、无法逐条阅读。
- **首行带关键字与条数**：`📰 「{关键字}」相关资讯 · 共 {N} 条`，让用户一眼知道查了什么、有多少条。
- **分隔线区隔**：每条资讯之间用 `━━━━━━━━━━━━━━━━━━━━` 分隔，排版清晰、一目了然。
- **标题保真**：标题取脚本返回的 `title`，原样展示，不改写、不夸大。
- **时间必带**：`⏰` 处展示脚本返回的 `time`（格式 `YYYY-MM-DD HH:MM`），方便用户判断时效。
- **摘要口语化**：`📝` 处根据 `content` 字段**提炼**核心信息，一句话讲清重点，去除冗余修饰词，控制在 100 字以内、超出用 `…` 省略；不要直接粘贴整段原文，避免「像从网上扒下来的」。
- **每条必带跳转**：`🔗 查看更多 →` 后接该条资讯的真实 `url`（形如 `https://content.jr.jd.com/article/index.html?...`），供用户点击查看原文。缺少 url 时省略该行。
- **按返回顺序展示**：默认按脚本返回顺序（一般为相关度/时间序）展示，如条数多可只展示前 5～10 条。
- **emoji 仅作视觉引导**：📰 标题区、⏰ 时间、📝 摘要、🔗 链接，克制使用，保持专业感。

## 结尾来源标注（硬性要求）

- 结尾**必须原样保留**脚本返回的 `source.attribution`：
  `💡 本信息由 [京东金融](https://u3.jr.jd.com/downloadApp/download2v.html?id=16276&activityId=13897) 提供`
- 来源名称与链接由 `scripts/jdjr_config.py` 或环境变量控制，不得删除或篡改。

## 失败与空结果处理

- 接口失败 → 「服务异常，请稍后重试」，**不要编造资讯内容**。
- 查不到数据 → 「未找到关于「{关键字}」的相关资讯」。
