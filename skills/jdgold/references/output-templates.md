# 回答模板合集（Agent 输出格式规范）

> 本文件定义各场景的对客输出模板。SKILL.md 通过引用（`详见 output-templates.md §场景名`）指向本文件。

---

## §金价

```
【{标的名称}】
实时价格：{价格} {单位}
涨跌幅：{涨跌幅}%
涨跌额：{涨跌额}
今开：{今日开盘价}  昨收：{昨日收盘价}
最高：{最高价}   最低：{最低价}
交易时间：{交易时间}
```

**展示规则：**
- **红涨绿跌（用 emoji 标注方向，不用箭头、不用 HTML span）**：涨（正值）加 🔴，跌（负值）加 🟢，平盘加 ⚪或省略。**严禁使用 `<span style="color:...">` 等内联 HTML 富文本**。**也不要使用 ▲▼ 等箭头符号**。
  - **标准写法**：涨用 `🔴 +0.86%`、跌用 `🟢 -0.90%`、平用 `⚪ 0.00%`。脚本层已按此格式输出，Agent 转述时保持原样即可。
- **禁止对客展示行情代码（uniqueCode，如 WG-JDAU、CMBC-JCJ 等）**。

**单位规则：**
- 银行积存金：人民币/克
- 国际金价（伦敦金/暗金）：美元/盎司
- 京东24h金价：人民币/克（综合国内积存金报价）

## §金价走势分析

```
【{标的名称} · 走势分析】
当日整体：较昨收{平盘/温和涨/明显涨/大幅涨/…}（{涨跌幅}%）。
日内振幅：{振幅}%（最高 {最高价} / 最低 {最低价}）。
{开盘后走高，多头占优 / 开盘后走低，空头占优 / 现价与开盘持平}。
现价处于日内{高位区/中部区间/低位区}（约 {位置}%）。
提示：以上为当日实时数据解读，非投资建议，金价受多重因素影响。
```

- 走势分析**只解读接口返回的当日真实数据**（开/收/高/低/涨跌幅），**不预测、不编造、不臆测未来**。
- 结尾必须带风险提示「非投资建议」。

## §持仓/收益

脚本 `holdings_entry.py` 已直接产出**可视化 Markdown**（主副标题 + emoji + 加粗 + 表格，含涨跌 emoji 🔺🔻➖），**直接转述脚本输出即可，勿改写为分行罗列，勿删减或替换脚本已带的 emoji**。

**收益视角**（`--intent income`）

```
## 📈 我的黄金收益

### 📊 汇总

| 💰 累计卖出收益(元) |
| ---: |
| +6,548.21 |

### 🏦 各银行明细

| 🏦 银行 | 💰 累计卖出收益(元) |
| --- | ---: |
| 民生银行 | +2,443.31 |
| 工商银行 | +77.63 |
```

**持仓/两者视角**（`--intent holdings` / `both`）

```
## 💰 我的黄金持仓与收益

### 📊 汇总

| ⚖️ 总持仓(克) | 💵 平均成本价(元/克) | 💎 当前持仓价值(元) | 📈 当前持仓收益(元) | 💰 累计卖出收益(元) |
| ---: | ---: | ---: | ---: | ---: |
| {克数} | {价格} | {金额} | {金额}（{百分比}%） | {金额} |

### 🏦 各银行明细

| 🏦 银行 | ⚖️ 持仓(克) | 💵 成本均价(元/克) | 📈 实时金价(元/克) | 💎 持仓价值(元) | 📊 当前持仓收益(元) | 💰 累计卖出收益(元) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| {银行名} | {克数} | {价格} | {实时金价} | {价值} | {金额} | {金额} |

> 🕒 数据更新时间：{时间}
```

**格式要求：**
- 持仓与收益一律以 **Markdown 表格 + 汇总卡片** 呈现。收益正负用 `+/-` 号表达即可，**不要添加 🔺🔻➖ 等方向符号**；关键数值加粗。
- **展示范围**：须包含接口返回的**所有有持仓或有收益的银行**，包括已清仓但仍有累计卖出收益的银行。
- **当前持仓价值 = 各银行持仓克重 × 该银行积存金实时金价 之和**；严禁用京东24h金价统一计算。
- **累计卖出收益直接透传接口 `totalIncome`（后端已算好），不用实时金价重算**。
- **当前持仓收益 = 当前持仓价值 − 持仓成本**；百分比 = 当前持仓收益 ÷ 持仓成本 × 100%。
- **实时金价缺失兜底**：用已取到的任一家实时价作兜底价估算（缺价行标 `*`、汇总标「含估算」、脚注注明来源）。仅当全部取不到时才跳过。
- 数值保留合适的小数位（克数 2~4 位，金额、单价 2 位）。

## §早报

```
📅 {日期}  ·  黄金早报

📌 {一句话核心结论}

━━━━━━━━━━━━━━━━━━━━

🔍 今日看点

- 金价走势：{涨/跌，一句话}
- 市场驱动：{关键事件/政策 → 对金价的影响}
- 盘面表现：{当前价位与关键点位}
- 短期研判：{偏多/偏空/震荡，理由}

━━━━━━━━━━━━━━━━━━━━

🔗 查看原文：{jumpUrl}
```

- **时间必带**：首行必须展示日期。
- **一句话结论**：📌 处先给一句最关键的当日结论。
- **要点分点**：根据 `content` 提炼，不直接粘贴原文；每个要点一行、口语化、简短。
- **结尾附链接**：给出原文链接供用户查看详情。

```
| 项目 | 数值 |
|------|------|
| ⚖️ 总持仓 | **{克数} 克** |

| 📈 浮动盈亏 | **{金额} 元** |
| 📊 浮盈浮亏比 | **{百分比}%** |

### 二、🏦 各银行明细

| 🏦 银行 | ⚖️ 持仓(克) | 💵 成本均价(元/克) | 📈 实时金价(元/克) | 💎 当前价值(元) | 💰 累计卖出收益(元) | 📊 浮动盈亏(元) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| {银行名} | {克数} | {价格} | {实时金价} | {价值} | {金额} | {金额} |

### 三、市场参考（黄金早报）

- {早报标题}

（注：早报金价多为美元/盎司，仅作市场趋势参考，不用于元/克口径的浮盈计算）

### 四、诊断结论与建议

- **诊断**：{轻仓浮亏/轻仓浮盈/重仓浮亏/重仓浮盈/成本接近平价/金价暂不可用}
- **心态建议**：{心态建议}
- **操作建议**：
  1. {建议1}
  2. {建议2}
  3. {建议3}

### 五、风险提示

- 以上分析仅供参考，不构成投资建议
- 黄金价格受国际政治、经济等多重因素影响，存在波动风险
- 投资决策请结合个人风险承受能力谨慎做出
```

**诊断框架（四维）：**
1. 仓位占比：总成本 ≤5万→轻仓，5-20万→中等，>20万→重仓
2. 浮盈浮亏状态：浮盈浮亏比 >5%→浮盈，<-5%→浮亏，其余→接近平价
3. 集中度：仅1家银行有持仓→集中
4. 场景匹配：6种场景（轻仓浮亏/轻仓浮盈/重仓浮亏/重仓浮盈/接近平价/金价不可用）

## §功能汇报格式

当用户询问本 Skill 功能时：

```
## 🏅 京东金融·黄金助手 · 能为您做这些

### 1. 行情查询（无需登录）

- 实时金价：京东24h金价、上金所黄金9999、伦敦金、暗金，以及民生/浙商/兴业/广发/工商/中信/浦发 7 家银行积存金
- 贵金属行情：黄金 / 白银 / 铂金实时价与历史走势、日/周/月 K 线
- 综合分析：实时行情、资金动向、交易机会评分、共振分析

### 2. 资讯查询（无需登录）

- 黄金资讯：黄金快讯与相关新闻资讯（统一入口）
- 黄金早报：当日市场早报与看点
- 大V排行：黄金理财达人收益榜 / 人气榜 / 加仓榜

### 3. 账户查询（需登录授权）

- 持仓与收益：各银行积存金持仓汇总、浮盈浮亏
- 持仓诊断：结合行情给出加减仓 / 止盈止损等操作建议
- 交易记录：买入/卖出/赠金/条件单记录

💡 直接说「今日金价」「我的持仓」「黄金快讯」等即可，也可指定具体银行或标的。

💡 本信息由 [京东金融](https://u3.jr.jd.com/downloadApp/download2v.html?id=16276&activityId=13897) 提供
```

**规则：**
- 三大类顺序固定：行情 → 资讯 → 账户
- 标的/维度用业务名，禁止出现 uniqueCode、接口名、脚本名
- 结尾必带来源标注
